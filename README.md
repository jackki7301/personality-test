# personality-test

# 나만의 정밀 성향 분석 테스트 (10문항)

2주차 과제로 제작한 웹 기반 인터랙티브 성향 분석 테스트 프로그램입니다.
10가지 일상 상황 질문을 통해 사용자의 성향을 분석하고, 상황별 일러스트 배경과 효과음, 결과 비율 및 유형별 궁합 정보를 제공합니다.

## 주요 기능
1. 10문항 정밀 성향 분석: 신중·계획형과 활동·즉흥형 비율을 계산하여 3가지 유형(신중한 탐구형, 활동적인 즉흥형, 유연한 조화형)으로 결과 도출
2. 실시간 상황 일러스트 전환: 질문과 선택지에 마우스를 올리면 각 상황에 맞는 31종의 벡터 일러스트 배경이 부드럽게 전환
3. Web Audio API 효과음 및 시각 효과: 버튼 클릭음, 결과 발표 팡파레 효과음(우측 상단 버튼으로 On/Off 가능) 및 축하 폭죽 애니메이션 지원
4. 반응형 웹 디자인: PC와 스마트폰 화면 크기에 맞춰 자동으로 최적화

## 사용 방법
1. 배포된 웹사이트 주소(github.io)로 접속합니다.
2. 시작 화면 입력창에 이름 또는 닉네임을 입력하고 **테스트 시작하기** 버튼을 누릅니다.
3. 총 10개의 질문에서 자신에게 더 가까운 선택지를 클릭합니다.
4. 분석이 완료되면 성향 유형, 비율 게이지 바, 환상의 짝꿍 및 주의할 유형을 확인하고 **다시 테스트하기**로 재실행할 수 있습니다.
